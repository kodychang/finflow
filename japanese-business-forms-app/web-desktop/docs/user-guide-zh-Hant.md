# Shoko Forms Desktop 完整功能教程

本文面向日常使用者、管理者與客服支援人員，說明 Shoko Forms Desktop 的每一個主要功能，以及跨項目、跨表單的實務應用方式。

## 1. 產品使用總覽

Shoko Forms Desktop 用於在本機建立、管理、預覽與輸出日式業務帳票。資料保存在使用者選擇的本地資料夾，可匯出為 `.shokobackup`，並與 iOS App 或另一台桌面電腦交換資料。

標準工作流程：

1. 登入授權碼。
2. 確認本地資料夾。
3. 建立或匯入資料。
4. 建立項目。
5. 在項目內建立帳票。
6. 填寫客戶、公司、商品、明細與備註。
7. 預覽 PDF，調整印章與版面。
8. 保存、列印或匯出 PDF。
9. 定期匯出 `.shokobackup` 備份。

## 2. 第一次啟動

### 2.1 授權碼登入

桌面版需要有效授權碼才能進入系統。

操作步驟：

1. 開啟 Shoko Forms Desktop。
2. 在授權碼登入頁輸入完整授權碼。
3. 按下登入或保存授權資料。
4. 驗證成功後進入首頁。

使用場景：

- 新客戶第一次安裝桌面版。
- 客戶更換電腦後重新登入。
- 授權到期後輸入新的授權碼。

注意事項：

- 授權碼保存在本機。
- 登出授權碼後會立即回到登入頁。
- 重新進入系統前必須再次輸入有效授權碼。

### 2.2 本地資料夾設定

第一次啟動時，系統會要求確認桌面端資料夾。該資料夾會保存本機工作資料、匯入紀錄、匯出檔案與歷史備份。

資料夾內通常包含：

- `state.json`：目前工作資料。
- `backups/`：歷史備份。
- `imports/`：匯入紀錄。
- `exports/`：匯出紀錄。
- `temp/`：暫存檔案。

操作建議：

- 放在固定位置，例如文件資料夾或公司指定資料夾。
- 不要放在會被清理工具刪除的暫存目錄。
- 更換資料夾前先匯出 `.shokobackup`。

跨設備場景：

- 舊電腦先匯出 `.shokobackup`。
- 新電腦設定新的本地資料夾。
- 在新電腦匯入備份，選擇合併或替換。

## 3. 首頁與導航

首頁集中顯示近期資料、資料統計與主要入口。

主要導航：

- 首頁：查看總覽與快速操作。
- 帳票：建立與編輯表單。
- 公司列表：管理發行公司資料。
- 檔案列表：按表單與檔案查看文件。
- 項目列表：按項目集中管理多張相關表單。
- 客戶列表：管理客戶或供應商主檔。
- 商品列表：管理品項、型號、規格與單價。
- 模板列表：管理付款資訊、備考與交易條件。
- 印章管理：管理共用印章圖片。
- 設定：語言、PDF、配色、授權、資料夾與支援。

建議使用方式：

- 新手從首頁的新增帳票開始。
- 日常查找從項目列表或檔案列表開始。
- 月底整理從項目列表與搜尋功能開始。
- 管理基礎資料時使用公司、客戶、商品與模板列表。

## 4. 帳票功能教程

### 4.1 新增帳票

操作步驟：

1. 進入首頁或帳票頁。
2. 點擊新增帳票。
3. 選擇項目類型：客戶或供應商。
4. 選擇建立新項目，或選取現有項目。
5. 選擇表單類型。
6. 系統建立表單並進入編輯畫面。

使用場景：

- 新客戶詢價，建立見積書。
- 已成交後建立納品書與請求書。
- 收款後建立領収書。
- 收到供應商報價 PDF，建立仕入先見積記録。
- 要向供應商下單，建立発注書。

### 4.2 客戶類帳票

客戶類帳票用於對外面向客戶的銷售、交付、請款與收款流程。

包含：

- 見積書：報價給客戶。
- 受注ファイル：保存客戶訂單或確認資料。
- 納品書：確認已交付商品或服務。
- 請求書：向客戶請款。
- 領収書：確認已收到款項。

典型流程：

1. 客戶詢價，建立見積書。
2. 客戶確認後，建立受注ファイル並附上訂單 PDF 或截圖。
3. 出貨或完成服務後，建立納品書。
4. 需要請款時，建立請求書。
5. 客戶付款後，建立領収書。

### 4.3 供應商類帳票

供應商類帳票用於採購、收貨、供應商請款與付款憑證管理。

包含：

- 仕入先見積記録：保存供應商報價。
- 発注書：向供應商發出採購需求。
- 受領書：記錄收貨或驗收。
- 仕入先請求書記録：保存供應商請款資料。
- 仕入先領収書記録：保存付款後取得的收據。

典型流程：

1. 收到供應商報價，建立仕入先見積記録並附上 PDF。
2. 決定採購後，建立発注書。
3. 收貨或服務完成後，建立受領書。
4. 收到供應商請求書，建立仕入先請求書記録。
5. 付款完成後，建立仕入先領収書記録。

### 4.4 帳票基本欄位

常用欄位：

- 帳票編號：列表、搜尋與 PDF 上的識別編號。
- 發行日：帳票開具日期。
- 交易年月日：交易、交付或付款發生日期。
- 支払期限：請求書或付款通知的付款期限。
- 關聯號：用來串聯前後表單，例如報價單號、發注書號、請求書號。
- 項目名稱：讓表單歸屬到同一項目。

應用建議：

- 同一項目的所有表單使用一致的項目名稱。
- 關聯號填入上一階段表單編號。
- 編號可以手動調整為公司內部規則。

### 4.5 客戶 / 供應商資訊

帳票會依類型顯示客戶或仕入先資訊。

可填欄位：

- 名稱。
- 聯絡人。
- 電話。
- Email。
- 地址。

使用方式：

- 可直接輸入新名稱。
- 可從客戶列表選取既有資料。
- 選取主檔後，聯絡資料會自動帶入。
- 可從目前帳票建立或更新客戶主檔。

跨表單應用：

- 客戶資料建好後，見積書、納品書、請求書與領収書都可以重複使用。
- 供應商資料建好後，供應商報價、發注書、受領書與請款記錄都可以重複使用。

### 4.6 發行公司資訊

發行公司代表帳票上的開票方或公司方資訊。

可填欄位：

- 公司名稱。
- 登錄番號。
- 聯絡人。
- 電話。
- Email。
- 地址。
- Logo。
- Logo 縮放。

使用場景：

- 一間公司使用固定開票資料。
- 多品牌或多法人需要切換不同發行公司。
- 請求書與領収書需要顯示適格請求書登錄番號。

### 4.7 商品明細

商品明細用於需要金額計算的帳票，例如見積書、請求書、領収書與発注書。

可填欄位：

- 品名。
- 型號。
- 規格。
- 數量。
- 單價。

操作方式：

- 點擊新增明細增加一行。
- 品名可從商品列表選取。
- 選取商品後可帶入型號、規格與單價。
- 系統依數量、單價與稅率計算小計、稅額與合計。

應用建議：

- 常用商品先建立商品主檔。
- 臨時項目可直接在帳票內輸入。
- 發注書可用同一套商品資料向供應商下單。

### 4.8 備考、交易條件與付款資訊

文字欄位適合保存固定說明或每張表單的特殊條件。

常見用途：

- 見積條件。
- 交期說明。
- 請款條件。
- 振込先。
- 付款期限提醒。
- 客戶特殊要求。

模板應用：

- 常用文字可先存入模板列表。
- 建立表單時從模板選取，減少重複輸入。
- 不同語言或不同客戶可建立不同模板。

### 4.9 附件上傳

部分表單支援上傳圖片或 PDF，適合保存外部收到的文件。

支援場景：

- 客戶訂單 PDF。
- LINE 或 Email 截圖。
- 供應商報價 PDF。
- 供應商請求書 PDF。
- 供應商領収書圖片。
- 付款證明。

操作步驟：

1. 打開支援附件的表單。
2. 點擊上傳圖片 / PDF。
3. 選擇檔案。
4. 在下方預覽區確認內容。
5. 保存表單。

注意事項：

- 圖片與 PDF 會保存在本地資料中。
- PDF 一次導入通常以單一檔案為主。
- 建議檔名保留來源與日期，方便追蹤。

## 5. 項目管理教程

### 5.1 什麼是項目

項目是用來集中管理多張相關帳票的單位。它可以是一筆客戶案件、一個工程、一張採購單、一批商品銷售，或任何需要把多張表單放在一起追蹤的業務活動。

項目通常包含：

- 項目名稱。
- 項目類型：客戶或供應商。
- 客戶 / 供應商名稱。
- 多張相關表單。
- 更新日期與完成狀態。

### 5.2 建立新項目

操作步驟：

1. 點擊新增帳票或進入項目列表。
2. 選擇客戶項目或供應商項目。
3. 輸入客戶 / 供應商名稱。
4. 輸入項目名稱。
5. 選擇要建立的表單。

命名建議：

- `2026-06 客戶名 工程名稱`
- `2026-06 供應商名 採購內容`
- `客戶名 / 案件編號 / 地點`

### 5.3 放入既有項目

當表單屬於已存在的案件時，應放入既有項目。

使用場景：

- 已有見積書，後續新增請求書。
- 已有供應商報價，後續新增発注書。
- 已有項目，補上客戶訂單 PDF。

操作步驟：

1. 新增帳票。
2. 選擇現有項目。
3. 選取目標項目。
4. 選擇表單類型。
5. 決定新增一份或覆蓋既有同類表單。

### 5.4 新增與覆蓋同類表單

同一項目內可能已有同類表單。系統會讓使用者選擇新增或覆蓋。

選擇新增：

- 適合多次報價。
- 適合分批請款。
- 適合多張供應商發票。
- 適合保留歷史版本。

選擇覆蓋：

- 適合原表單建錯。
- 適合剛建立後發現類型選錯。
- 適合不需要保留舊版本的修正。

建議：

- 覆蓋前先預覽現有 PDF。
- 正式已發給客戶的表單不要輕易覆蓋。
- 有審計需求時使用新增，保留版本。

### 5.5 項目列表

項目列表用來按客戶或供應商流程集中查看表單完成度。

可做操作：

- 搜尋項目。
- 查看項目內有哪些表單。
- 打開表單編輯。
- 複製表單到其他項目。
- 編輯項目資料。
- 刪除項目或項目內表單。

應用場景：

- 月底查看哪些項目還未請款。
- 檢查供應商請求書是否已有付款收據。
- 找出同一客戶最近的所有案件。

## 6. 主檔管理教程

### 6.1 客戶列表

客戶列表保存客戶與供應商基本資料。

可管理欄位：

- 名稱。
- 聯絡人。
- 電話。
- Email。
- 地址。

使用方式：

- 新增客戶。
- 編輯客戶。
- 刪除客戶。
- 在帳票中選取並帶入資料。
- 從帳票反向建立或更新客戶資料。

### 6.2 公司列表

公司列表保存發行公司資料。

使用場景：

- 同一公司固定開票。
- 多公司切換開票方。
- 需要保存登錄番號與 Logo。

### 6.3 商品列表

商品列表保存常用品項。

可管理欄位：

- 品名。
- 型號。
- 規格。
- 單價。

應用場景：

- 見積書快速帶入商品。
- 請求書沿用常用價格。
- 発注書使用相同商品資訊向供應商下單。

### 6.4 模板列表

模板列表保存可重複使用的文字。

模板類型：

- 付款資訊。
- 備考。
- 交易條件。

應用場景：

- 不同銀行帳戶建立不同付款模板。
- 日文、中文、英文各建一組條件。
- 常見交期、保固、有效期限重複使用。

## 7. PDF 與印章教程

### 7.1 PDF 預覽

PDF 預覽會依目前帳票內容即時生成 A4 版面。

預覽前檢查：

- 客戶或供應商名稱是否正確。
- 發行公司資料是否完整。
- 日期與付款期限是否正確。
- 明細、稅率與合計是否正確。
- 備考與交易條件是否完整。
- 印章位置是否正確。

### 7.2 PDF 語言

PDF 語言與操作界面語言可分開設定。

支援用途：

- 內部人員使用中文界面，輸出日文 PDF 給日本客戶。
- 內部使用日文界面，輸出英文 PDF 給海外客戶。
- 依客戶語言切換 PDF 帳票文字。

### 7.3 帳票配色

可設定新建表單的預設配色，也可套用到目前正在編輯的表單。

常見配色：

- 日本帳票。
- 海藍表格。
- 薄荷表格。
- 玫瑰表格。
- 琥珀表格。
- 石墨表格。

建議：

- 正式日式商務文件使用日本帳票或石墨表格。
- 對外提案可使用較柔和的配色。
- 同一客戶或同一公司盡量保持一致風格。

### 7.4 保存、打開與列印 PDF

操作方式：

1. 打開 PDF 預覽。
2. 確認版面與內容。
3. 點擊保存並打開 PDF。
4. 系統生成 PDF 檔案並打開。
5. 如需紙本，使用列印 / PDF 功能。

### 7.5 印章管理

印章管理頁用於保存桌面端共用印章圖片。

操作：

- 上傳印章。
- 查看印章列表。
- 移除印章。

注意：

- 這裡管理的是共用印章圖片。
- 每份帳票是否套用印章，以及位置與樣式，要在 PDF 預覽中的印章設定調整。

### 7.6 單張帳票印章設定

在 PDF 預覽中可調整：

- 使用哪一個印章。
- 是否顯示印章。
- 左右位置。
- 上下位置。
- 大小。
- 旋轉。
- 透明度。
- 亮度。
- 對比。
- 是否啟用印章色。
- 印章色。
- 是否去除白底。
- 裁切範圍。

操作技巧：

- 可直接在 PDF 頁面上點擊或拖曳印章位置。
- 調整完成後保存此帳票印章設定。
- 不同帳票可以使用同一印章但不同位置。

## 8. 備份、匯入與匯出教程

### 8.1 匯出備份

匯出備份會把目前本地資料打包成 `.shokobackup`。

包含資料：

- 帳票。
- 客戶。
- 公司。
- 商品。
- 模板。
- 草稿。

使用場景：

- 換電腦前備份。
- 發送資料到 iOS App。
- 每日或每週手動保存版本。
- 客服需要重現問題時提供測試資料。

### 8.2 匯入備份：合併

合併模式會保留目前資料，並加入備份中不存在的新資料。

適合：

- 從 iPhone 匯入新建表單。
- 從另一台電腦帶回資料。
- 多來源資料整合。

注意：

- 若資料 ID 相同，系統會避免重複加入。
- 合併後建議檢查項目列表與檔案列表。

### 8.3 匯入備份：替換

替換模式會用匯入檔案重建本地資料。

適合：

- 新電腦第一次導入完整資料。
- 要回復到某個備份版本。
- demo 資料試用。

風險：

- 目前本地資料會被替換。
- 操作前應先匯出目前資料，保留可恢復版本。

### 8.4 與 iOS App 互通

桌面版匯出的 `.shokobackup` 可交給 iOS App 開啟。

流程：

1. 在桌面版匯出備份。
2. 透過 AirDrop、iCloud Drive、Email 或其他方式傳到 iPhone。
3. 在 iPhone 使用 Shoko Forms App 開啟。
4. 在 iOS App 選擇合併或替換。

iOS 到桌面：

1. 在 iOS App 匯出 `.shokobackup`。
2. 將檔案傳到電腦。
3. 在桌面版選擇匯入。
4. 根據需求選擇合併或替換。

## 9. 設定與維護教程

### 9.1 操作界面語言

操作界面語言影響系統按鈕、導航與提示文字。

使用場景：

- 員工習慣中文操作。
- 日本辦公室使用日文操作。
- 英文使用者需要英文界面。

### 9.2 PDF 帳票語言

PDF 帳票語言影響輸出給客戶或供應商的帳票文字。

應用建議：

## 10. 跨項目應用場景

### 10.1 同一客戶多個項目

場景：

同一客戶同時有多個工程或訂單，每個案件需要獨立追蹤報價、交付、請款與收款。

做法：

1. 為每個案件建立不同項目名稱。
2. 客戶名稱使用同一客戶主檔。
3. 每個項目內建立自己的見積書、納品書、請求書與領収書。
4. 月底從項目列表檢查每個項目狀態。

好處：

- 不會把不同案件的請款混在一起。
- 同一客戶資料可重複使用。
- 項目完成度清楚。

### 10.2 同一供應商多個採購項目

場景：

同一供應商提供不同材料或服務，每個採購項目有不同報價、發注、收貨與請款資料。

做法：

1. 以供應商建立供應商項目。
2. 每個採購主題建立不同項目名稱。
3. 將供應商報價、発注書、受領書、請求書與領収書放在同一項目。
4. 用關聯號串接供應商文件號碼。

### 10.3 客戶項目與供應商項目並行

場景：

一個客戶工程需要向多個供應商採購材料。

做法：

1. 建立客戶項目，管理對客戶的見積、納品、請款與收據。
2. 分別建立供應商項目，管理各供應商報價、發注與請款。
3. 在項目名稱中使用共同案件名。
4. 在關聯號或備考中寫入客戶項目編號。

範例：

- 客戶項目：`2026-06 ABC商事 店舗改装`
- 供應商項目：`2026-06 XYZ建材 ABC商事店舗改装`
- 供應商項目：`2026-06 電工A ABC商事店舗改装`

### 10.4 將表單複製到其他項目

場景：

某張表單可作為另一個項目的基礎，例如相似報價或相似採購。

做法：

1. 在項目列表或檔案列表找到來源表單。
2. 選擇複製到項目。
3. 選擇目標項目。
4. 檢查客戶、供應商、日期、金額與備註。
5. 保存為新表單。

注意：

- 複製後必須重新確認收件方與金額。
- 不要直接沿用錯誤的關聯號。

### 10.5 未指定項目的整理

場景：

匯入資料或快速建立表單時，部分資料沒有項目名稱。

整理方式：

1. 在項目列表找到未指定項目。
2. 編輯項目名稱。
3. 補上客戶或供應商名稱。
4. 將相關表單集中到正確項目。

## 11. 跨表單應用場景

### 11.1 見積書到領収書

完整客戶流程：

1. 見積書：提出價格與條件。
2. 受注ファイル：保存客戶確認資料。
3. 納品書：交付完成後開立。
4. 請求書：向客戶請款。
5. 領収書：收到款項後開立。

關聯方式：

- 請求書的關聯號填見積書或納品書編號。
- 領収書的關聯號填請求書編號。
- 所有表單使用同一項目名稱。

### 11.2 受注ファイル到請求書

場景：

客戶直接提供訂單，不需要先建立見積書。

流程：

1. 建立受注ファイル並上傳客戶訂單。
2. 根據訂單建立納品書。
3. 建立請求書。
4. 收款後建立領収書。

適合：

- 長期客戶固定下單。
- Email 或 PDF 訂單為正式依據。
- 客戶內部採購單是交易起點。

### 11.3 供應商報價到付款憑證

完整採購流程：

1. 仕入先見積記録：保存供應商報價。
2. 発注書：向供應商下單。
3. 受領書：收貨或驗收。
4. 仕入先請求書記録：保存供應商請款文件。
5. 仕入先領収書記録：保存付款後取得的收據。

關聯方式：

- 発注書關聯供應商報價。
- 供應商請求書關聯発注書。
- 供應商領収書關聯請求書或付款紀錄。

### 11.4 客戶請款與供應商請款對照

場景：

同一案件既要向客戶請款，也要支付供應商。

做法：

1. 客戶項目建立請求書。
2. 供應商項目建立仕入先請求書記録。
3. 在兩邊備考中記錄共同案件名。
4. 月底核對客戶收入與供應商成本。

### 11.5 多張同類表單

場景：

同一項目可能有多張請求書或多張供應商請求書。

常見原因：

- 分批交付。
- 分期請款。
- 追加工程。
- 多次修正報價。
- 供應商分批開票。

建議：

- 使用新增一份，不要覆蓋已正式發出的表單。
- 編號加入批次或版本。
- 備考中寫清楚第幾次、哪個範圍。

## 12. 實務案例

### 12.1 工程項目

流程：

1. 建立客戶項目：`2026-06 客戶名 店舗改装`
2. 建立見積書。
3. 客戶確認後上傳受注資料。
4. 向供應商建立採購項目。
5. 保存供應商報價並建立発注書。
6. 完工後建立納品書。
7. 建立請求書。
8. 收款後建立領収書。
9. 供應商付款後保存供應商領収書。

### 12.2 商品銷售出貨

流程：

1. 先建立商品主檔。
2. 建立客戶項目。
3. 用商品主檔快速建立見積書。
4. 客戶下單後建立受注ファイル。
5. 出貨時建立納品書。
6. 月底建立請求書。
7. 收款後建立領収書。

### 12.3 採購與供應商付款

流程：

1. 收到供應商報價 PDF。
2. 建立仕入先見積記録並上傳 PDF。
3. 建立発注書。
4. 收貨後建立受領書。
5. 收到請求書後建立仕入先請求書記録。
6. 付款後建立仕入先領収書記録。

### 12.4 多語言 PDF

場景：

內部使用中文操作，但需要輸出日文或英文 PDF。

做法：

1. 在設定中保持操作界面為中文。
2. 將 PDF 帳票語言改為日文或英文。
3. 打開帳票 PDF 預覽。
4. 確認標題、欄位、金額與備註。
5. 保存 PDF。

### 12.5 月底集中請款

流程：

1. 進入項目列表。
2. 搜尋本月完成的客戶項目。
3. 檢查是否已有納品書。
4. 對未請款項目建立請求書。
5. 預覽 PDF，確認金額。
6. 匯出或列印請求書。
7. 收款後逐一建立領収書。

## 13. 日常安全檢查清單

每日或每週：

- 確認重要表單已保存。
- 匯出 `.shokobackup`。
- 檢查本地資料夾位置。
- 確認 PDF 已保存到公司指定位置。

匯入前：

- 先匯出目前資料。
- 確認匯入模式是合併還是替換。
- 匯入後檢查項目數、客戶數與表單數。

發送 PDF 前：

- 確認收件方名稱。
- 確認日期與付款期限。
- 確認金額、稅率與合計。
- 確認公司資訊與登錄番號。
- 確認印章位置。
- 確認 PDF 語言。

刪除或覆蓋前：

- 確認是否已正式發出。
- 確認是否需要保留歷史版本。
- 必要時先匯出備份。
