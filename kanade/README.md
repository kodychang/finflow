# Kanade（奏）— 技術設計文件

> **Kanade 是暫定代號**，非最終產品名。全文中的 `kanade` 命名空間（DB schema、API path、套件名）都可以整批改。

AI 創作者的音樂曲庫 + 日本店舖的合法 BGM 服務。

## 一句話定位

> **不是更便宜的 BGM，是不會聽膩的 BGM。**
> 曲庫全部為 AI 生成原創作品，不屬於 JASRAC／NexTone 管理範圍，店家無需另行申請。

## 三方關係

| 角色 | 得到什麼 | 付出什麼 |
|---|---|---|
| **創作者**（AI 音樂創作者） | 依實際商用播放次數持續分潤 | 上傳原創作品 + 權利聲明 |
| **聽眾** | 永遠免費聆聽 | — |
| **店家**（付費客戶） | 合法 BGM、情境自動切換、管理外証明書、再生ログ | 月額訂閱 |

平台收入來源＝**店家的 B2B 訂閱**。音樂本身不販售。
