# 01 — 產品與市場

## 1. 問題

日本的小型店舖（餐飲、美容、零售、診所）要在店內播放音樂，需要同時解決兩件事：

1. **音樂來源** — Spotify／Apple Music 的個人帳號依服務條款**禁止**商業場所使用
2. **著作權處理** — 播放 JASRAC／NexTone 管理曲目需要取得授權

現有解法都有明顯代價：

| 解法 | 月額（稅込） | 問題 |
|---|---|---|
| USEN MUSIC | ¥6,600〜 | 貴、初期費用 ¥22,000〜33,000 |
| OTORAKU | ¥3,278〜4,158 | 初期費用 ¥3,300 |
| モンスター・チャンネル | ¥2,068〜3,168 | — |
| Audiostock 店舗音楽 | ¥2,200 | 曲庫規模有限 |
| 廉價著作權自由服務（Simple BGM、BGMC Station、らくネット 等） | ¥350〜2,156 | **曲庫小、幾個月就聽膩** |
| 違規使用個人 Spotify | ¥0 | 違反服務條款 + 著作權風險 |

JASRAC 的 BGM 使用料本身其實不貴：

| 店舖面積 | 年額（稅別） | 月換算 |
|---|---|---|
| 500㎡ 以下 | ¥6,000 | 約 ¥500 |
| 1,000㎡ 以下 | ¥10,000 | 約 ¥833 |
| 3,000㎡ 以下 | ¥20,000 | 約 ¥1,667 |
| 6,000㎡ 以下 | ¥30,000 | ¥2,500 |
| 9,000㎡ 以下 | ¥40,000 | 約 ¥3,333 |
| 9,000㎡ 超 | ¥50,000 | 約 ¥4,167 |

> **關鍵認知：不能把「省下 JASRAC 費用」當賣點。** 小店一年才 ¥6,000，沒有人會為此更換服務商。真正的成本在音樂來源本身。

## 2. 兩個切入點

### 切入點 A：曲庫疲乏（現在就存在的痛點）

廉價著作權自由服務的曲庫規模在 5,000〜100,000 首之間且**固定不變**。店員一天工作 8 小時、一週 6 天，數個月內即可聽完整個曲庫。這是餐飲與美容業對 BGM 服務最普遍的抱怨，痛感高於價格。

**AI 生成音樂能提供、且只有 AI 能提供的：**

1. **永不重複** — 曲庫每日增長
2. **情境精準生成** — 不只是「爵士頻道」，而是「平日下午、雨天、客流稀疏、希望延長停留時間」
3. **品牌專屬曲庫** — 為單一店家生成的獨佔音樂，USEN 也做不到
4. **時段自動變化** — 早／午／晚自動切換氛圍

> ⚠️ **此假設尚未驗證。** 進入開發前必須完成 10〜20 家實地訪談，確認「聽膩」確實排在店家抱怨前三名。若否，定位須調整。詳見 [路線圖 Phase 0](09-roadmap.md)。

### 切入點 B：レコード演奏・伝達権（法規推力，3 年時間窗）

2026 年 6 月 17 日日本國會通過著作權法修正案，6 月 24 日公布，創設**レコード演奏・伝達権**。

| 項目 | 內容 |
|---|---|
| 權利性質 | **報酬請求權**（非排他權） |
| 徵收方式 | 文化廳指定團體統一徵收、分配（模式類似 JASRAC） |
| 適用範圍 | 商業用錄音的公開演奏、以接收裝置的公開傳達（店舖 BGM、活動等） |
| 受益人 | **實演家（歌手、演奏者）與錄音製作者** |
| 施行日 | 公布起 3 年內由政令定 → **最遲 2029 年 6 月** |

**影響：**

- 播放商業錄音的店家將**額外**負擔一筆費用（金額待指定團體訂定）
- USEN、OTORAKU、モンスター・チャンネル 等包含權利金的服務，成本結構被迫上調
- **AI 生成的原創作品不受影響**：無人類實演家；錄音製作者即上傳者本人，權利未委託任何團體

這是由立法保證的市場推力，而非市場預測。**但同時也是風險** — 指定團體若採概括徵收，舉證責任可能落在店家身上，這使得「管理外証明書 + 再生ログ」從加分功能變成**必要功能**。詳見 [權利鏈](04-rights-chain.md) 與 [風險登記表](10-risk-register.md)。

## 3. 定價

| 方案 | 月額（稅込） | 內容 |
|---|---|---|
| **Free** | ¥0 | 單店、3 個基本情境、每小時一次品牌語音提示、無証明書 |
| **Standard** | **¥1,980** | 全情境、排程、離線快取、**管理外証明書**、**再生ログ匯出**、無提示音 |
| **Custom** | **¥4,980** | Standard + **店舖專屬 AI 生成曲庫**、多分店管理、API |
| Enterprise | 個別報價 | 連鎖 20 店以上、SLA、專屬客服 |

**定價邏輯：**

- 對比 USEN ¥6,600 → 便宜約 70%
- 對比 Simple BGM ¥550 → 貴 3.6 倍，**必須用「不會聽膩」與「証明書」說服，絕不打價格戰**
- Free 方案的目的是裝機量與曲庫曝光，不是轉換漏斗的主力
- **年繳 8 折**，降低流失率並改善現金流

**手續費考量：** ¥1,980 的 Stripe 手續費約 3.6%（日本國內卡 3.6%，無固定費）。相較於單曲 ¥100〜300 的販售模式（手續費佔比可達 20%+），B2B 訂閱的單位經濟好得多。這是選擇此模式而非單曲販售的主要原因之一。

## 4. 創作者側

- 上傳免費、無數量限制（受配額規則約束）
- 聽眾端串流永遠免費
- **收入來源：商用播放分潤**（見 [08-payouts](08-payouts-and-billing.md)）
- 分潤池 = 商用訂閱淨收入 × **段階的分配率（30% → 45%）**，依實際商用播放秒數加權分配
  - 分配率隨有料店舖數階段性提高，且**只升不降**。理由與級距見 [08-payouts 第 3.2 節](08-payouts-and-billing.md#32-段階的分配率)
  - 固定 45% では 5 人体制の損益分岐点が 2,436 店となり、36ヶ月のロールアウト計画では到達しない
- 創作者後台可見：哪首曲子、在幾家店、播了幾次、產生多少收益

這個設計同時回答了「音樂如何自由又能產生收益」：**對聽眾免費，錢從商業使用者流向創作者。**

## 5. 明確不做的事

排除這些是為了保護核心價值與控制營運成本：

| 不做 | 理由 |
|---|---|
| 單曲／專輯販售 | 小額交易手續費佔比過高；且純 AI 生成作品的著作權地位不穩 |
| DRM | 傷害體驗，且與「音樂自由」定位衝突 |
| P2P 串流 | 零出口費用的物件儲存已使頻寬成本趨近於零；點播長尾使 P2P 效率極低；且削弱下架能力＝削弱法律地位 |
| 開放評論區／私訊 | 審核人力成本遠大於價值 |
| 公開追蹤數排行 | 必然引發刷量 |
| 平台餘額錢包 | 資金移轉業牌照風險，改用 Stripe Connect 直接分流 |
| 多國同時上線 | 各國集管團體制度差異巨大，法務工作量爆炸。**先做深日本市場** |
